# Atlas

Atlas is an experimental TypeScript framework for building AI agents from JSX components. These components describe an agent's context, tools, and behavior.

I'm building Atlas to find out whether declarative composition makes agents easier to understand and reason about.

The idea is to make an agent's context and available tools explicit on each turn.

There's prior art for this approach, but I haven't found an implementation I'd want to use. I want to find out whether the benefits hold up in practice.

## Early Development

I want to test this on workloads I run in my day-to-day work before claiming it makes anything easier.

This means I'm moving slowly and engineering this deliberately. I'm experimenting with the design and want to understand the decisions I'm making. If you have a request, open an issue and we can discuss it.
