# Atlas license in plain English

This document explains the Mozilla Public License 2.0. It is not a separate
license or legal advice. The full text in [LICENSE](LICENSE) governs your use
of Atlas. If this summary differs from that text, the license takes precedence.

You can use Atlas in commercial and closed-source applications. If you
distribute Atlas, you must preserve its required notices and make its source,
including your changes to covered files, available to recipients under MPL 2.0.
Your separate application code can stay private.

## Do: these are allowed

- Use Atlas for personal projects, company work, or commercial products.
- Charge for software built with Atlas.
- Fork Atlas, modify it, and build a competing product, provided you meet the
  distribution requirements below.
- Keep your own application code private when it lives in separate source files
  containing no copied Atlas code.
- Modify Atlas privately within your organization without publishing your changes.
- Run a modified Atlas on your servers without publishing changes merely because
  customers use the service. Sending code to their browsers does count as
  distribution.

## Do: when distributing Atlas or a modified version

- Make the covered source, including your changes, available to recipients under
  MPL 2.0.
- Tell recipients how to obtain that source and a copy of the license.
- Preserve existing license, copyright, patent, and warranty-disclaimer notices,
  subject to the license's exception for correcting factual inaccuracies.
- Make the corresponding editable source available when shipping compiled or
  minified code. Minified JavaScript alone does not satisfy this requirement.

## Don't: these would breach the license

- Ship a modified Atlas while withholding the covered source from recipients.
- Copy Atlas code into a new source file and distribute that file solely under
  proprietary terms.
- Strip required notices from the covered source.
- Impose terms that take away recipients' rights under MPL over the covered source.

## What sharing requires

You do not have to submit changes back to Atlas or publish them on GitHub.
You must make covered source available to recipients when the license requires
it. Those recipients can redistribute it under MPL.

MPL generally applies at the source-file level. Files containing Atlas code
remain covered; separate files containing only your own code can use another
license. Combining them in one application does not require you to release all
of your application's source.
